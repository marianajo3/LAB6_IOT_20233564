# Ejemplo Eureka para EcoHuerto

Abre primero [la guía rápida y completa](../docs/eureka/GUIA_COMPLETA.md). El ejemplo es independiente de Android y usa tres programas Spring Boot.

```powershell
mvn -f microservices/pom.xml clean package
```

Después ejecuta los tres JAR en terminales separadas como indica la guía. No hace falta configurar Firebase para esta demo local en memoria.
